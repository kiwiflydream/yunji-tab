# Yunji Tab · 云吉 Tab

简体中文 · [English](./README.en.md)

把浏览器里已经收藏的网站，变成打开新标签页就能找到的书签主页。

云吉 Tab 是一个开源的 Chrome 扩展。它沿用浏览器原有的书签和文件夹，提供搜索、标签、书签组和批量整理，也可以换上喜欢的主题。安装后即可使用，无需迁移书签或注册额外账号。

[Chrome 应用商店](https://chromewebstore.google.com/detail/mongacbicmimajjfljaaelfcchhkepbh) · [下载最新版本](https://github.com/kiwiflydream/yunji-tab/releases/latest) · [更新记录](https://github.com/kiwiflydream/yunji-tab/releases) · [反馈问题](https://github.com/kiwiflydream/yunji-tab/issues) · [开发指南](./docs/development.md)

## 安装

目前通过 GitHub Releases 提供 Chrome 安装包。

1. 打开[下载页面](https://github.com/kiwiflydream/yunji-tab/releases/latest)，下载名称为 `yunji-tab-<版本号>-chrome.zip` 的附件。页面自动生成的 `Source code` 是源码，不是安装包。
2. 解压 ZIP，确认目录内包含 `manifest.json`。
3. 在 Chrome 中打开 `chrome://extensions`，开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择刚才解压的目录。
5. 打开一个新标签页，开始使用。

升级时，用新版本文件替换原安装目录的内容，再到扩展管理页点击重新加载。保留安装目录，不必卸载扩展。

项目主要支持 Chrome。Edge、Brave 和 Opera 等 Chromium 浏览器可以尝试加载同一安装包，目前未逐一验证兼容性。Firefox 和 Safari 暂未提供正式安装包。

## 日常使用

### 快速找到收藏的网站

左侧分类沿用原有书签文件夹。常用网站可以置顶，也可以从「最近」「无标签」「无描述」等智能分类中继续整理。

顶部搜索框可以直接查找书签和目录，也支持 `tag:AI`、`site:github.com`、`folder:技术文档` 这样的筛选。切换到「网页」后，可以使用浏览器默认搜索引擎，或选择其他引擎。

![输入 tag:AI，查找不同文件夹中带有 AI 标签的书签](./docs/images/bookmark-search.png)

### 把一起使用的网站放进书签组

例如，把提问、阅读和检索工具放进一个「AI 工作台」。在「书签组」中点击「创建书签组」，填写标题和描述，从已保存的书签中选择成员；每个成员都能设置组内名称，还可以调整顺序和自定义组图标。

鼠标停留在组卡片上，或直接点击卡片，就会在当前页面展开名称列表，选择一个即可打开。书签组可以和普通书签一起置顶，不会改变成员原来的文件夹。删除组也不会删除原书签。

![书签组在当前页面展开成员名称，无需跳转到详情页](./docs/images/bookmark-groups.png)

书签组默认开启。不需要时，可在「设置 → 常规 → 书签组」中关闭，已有配置会保留。

### 给书签补上自己的说明

在卡片的「更多操作 → 编辑书签」中修改名称、网址和分类。展开「更多选项」，可以填写描述、标签、自定义图标，以及同一服务的备用 URL。图标支持 Emoji 或图片网址。

### 用备用 URL 自动选择访问入口

同一个服务可能有多个访问地址，比如家里的 NAS 同时提供外网域名和内网域名。把它们保存在同一个书签中，点击时，云吉 Tab 会同时探测主网址和备用 URL，自动打开最先响应的地址，省去切换网络后手动选择入口的麻烦。

例如，将 `https://nas.example.com` 填为主网址，在「更多选项 → 备用 URL」中填写内网地址 `http://nas.home.arpa`，多个备用地址每行一个：

| 使用环境            | 打开效果                                   |
| ------------------- | ------------------------------------------ |
| 外出使用公网        | 内网地址无法访问时，自动打开响应的外网域名 |
| 回家接入局域网      | 内网地址响应更快时，自动打开内网域名       |
| 连接 VPN 或组网工具 | 私有网络地址恢复可达后，也会参与自动选址   |

这也适合公司系统的内外网入口、自建服务的公网与 VPN 地址，或同一服务的多个等效访问入口。只需保存一个书签，就能随当前网络的访问情况选择地址。

选择依据是地址探测的响应速度。若所有地址都未探测成功，会回退打开主网址。

### 一次整理多个书签

点击「批量管理」，勾选书签后，可以一起移动、打开或删除，也可以拖动书签调整位置。

书签组也支持拖动卡片或拖拽柄调整顺序；在「置顶」中，书签组与普通书签可以混合排序。手动顺序会保存、参与浏览器同步，并包含在数据备份中。

删除后可以立即撤销；「更多操作 → 垃圾桶与历史」会保留最近 30 天的删除快照。整理较多收藏时，还可以使用「书签健康检查」查找重复、失效和重定向链接。

![批量管理：勾选多个书签后，统一移动、打开或删除](./docs/images/bookmark-bulk-actions.png)

### 换一个喜欢的主页风格

在「设置 › 外观」中选择简洁、平衡、紧凑、柔和、纸墨、蓝墨版画或电光蓝。分类栏可以放在左侧或顶部，书签也可以切换为紧凑视图。

首次安装或未配置风格时默认使用电光蓝，已有风格选择会保留。

电光蓝使用灰白底、电蓝文字和本地等宽字体，固定为浅色配色。该主题下强调色和背景选择不可用，导航位置与图标显示偏好仍会保留。

在「设置 → 外观 → 高级自定义 → 显示字段」中，“卡片图标”统一控制书签、文件夹和书签组卡片的图标，“菜单图标”控制分类导航图标。两项默认开启，刷新页面或切换主题会保留选择。

「常规」和「外观」页顶部都有「恢复默认」按钮，一键还原当前页的配置并保存。书签、书签组和自动整理规则会保留，常规设置中的语言会恢复为浏览器语言。

蓝墨版画采用深蓝与奶油白、衬线字体和印刷颗粒纹理，搭配项目原创的猫咪宇航员插画。插画固定在视窗底部，滚动书签时也能看到。

![蓝墨版画主题：深蓝底色、奶油白文字和猫咪宇航员插画](./docs/images/engraving-theme.png)

### 时间与天气

右上角显示时间、日期和天气。点击组件，或进入「设置 → 常规 → 时间与天气」，可以独立开关时间与天气、显示日期、切换 12/24 小时制、搜索城市和选择摄氏或华氏。天气需要手动选择城市并授权访问 Open-Meteo，不自动获取设备定位。

「设置 → 关于 → 更新记录」可以查看 [GitHub Releases](https://github.com/kiwiflydream/yunji-tab/releases)。

### 备份与恢复

打开「设置 › 数据与隐私」，可以导出、导入书签的补充数据，也可以用「完整快照」备份书签树及相关配置。WebDAV 使用同一份完整快照，备份范围如下：

| 包含 | 不包含 |
| ---- | ------ |
| 原生书签树、文件夹层级与顺序 | 标签页会话、垃圾桶、操作历史和缓存 |
| 描述、标签、自定义图标、备用 URL、置顶和收件箱状态 | AI API Token、WebDAV 连接配置和加密口令 |
| 书签组及成员顺序、目录图标、打开次数和最近访问时间、应用设置 | 浏览器同步的加密口令 |

完整快照恢复前会显示预览，确认后将原生书签树导入新的 `Yunji Tab Restore ...` 文件夹，保留现有原生书签。**同网址的补充数据和使用记录会恢复为快照中的值，书签组按 ID 恢复：同 ID 的组会被快照替换，当前已有的其他组会保留；应用设置会被快照替换。**这些恢复后的数据仍按浏览器和扩展的同步设置参与跨设备同步。

配置 WebDAV：

1. 填写目录地址，默认是坚果云 `https://dav.jianguoyun.com/dav/`，也可改为其他 WebDAV 服务或子目录。自定义目录需先在云盘中创建，远程服务需使用 HTTPS。
2. 填写账号和应用密码。坚果云账号为登录邮箱，应用密码在「账户信息 › 安全选项 › 第三方应用管理」中创建。
3. 按需填写「备份加密口令」，保存配置并测试连接；首次连接会申请该服务器的网站访问权限。
4. 手动备份，或开启「打开新标签页时自动备份」。自动备份默认关闭，开启后默认以 24 小时为最短检查间隔，也可选择 1、6 或 72 小时；达到间隔且内容变化时才上传。没有打开主页时不会定时运行，不需要 `alarms` 或通知权限。手动备份不受间隔和内容去重限制。

「备份加密口令」留空时上传普通 JSON；填写并保存一次后，后续手动、自动备份都会复用本机口令，使用 AES-256-GCM 加密完整快照，包含书签组。口令与补充数据的浏览器同步口令独立，仅保存在本机，不写入远端文件或快照。修改或清空口令只影响之后的备份，旧文件仍需创建时的口令。恢复时先尝试本机口令，缺少或不匹配时可临时输入；临时口令不修改已保存配置，解密成功后仍需预览并确认。遗忘口令后无法恢复对应的加密备份。

这项口令只用于 WebDAV 备份，手动导出的本地 JSON 仍为明文。

每次备份只上传一个独立 JSON，例如 `yunji-tab-backup-20261011T114025123Z-<随机 ID>.json`。文件名包含 UTC 时间（精确到毫秒）和随机 ID，避免覆盖历史版本。「同步记录」直接读取远端目录的文件列表，按时间倒序显示，支持刷新、恢复最新备份或恢复某条记录。换设备后连接同一目录即可查看记录；加密文件还需相应口令。上传失败或内容未变化时只显示当前状态，不产生文件记录。

记录不在本地持久保存，也不额外上传索引。旧版固定文件 `yunji-tab-full-snapshot.json` 和 `yunji-tab-snapshot-<随机 ID>.json` 也会显示，时间取服务器修改时间。扩展不自动删除远端文件，可在云盘中自行清理；清除连接配置只删除本机凭据、口令和检查状态，保留远端文件。

![数据与隐私设置：查看同步状态，导出数据或恢复完整快照](./docs/images/backup-and-restore.png)

### 更多整理工具

- **AI 分类**：在「设置 → AI」中配置自己的服务，让 AI 帮忙生成书签分类方案。先查看移动预览，确认后再应用。
- **标签页会话**：从主页「更多操作」打开会话管理，保存一组打开的标签页，方便稍后恢复。

## 跨设备同步与隐私

原生书签由浏览器负责同步；云吉 Tab 默认同步描述、标签、图标、备用 URL 等补充数据，书签组也支持跨设备同步。两台设备需使用同一 Chrome 账号、开启浏览器同步，并安装云吉 Tab。

可以在「设置 → 数据与隐私」查看同步状态、选择同步字段或启用补充数据的口令加密。**书签组通过独立的浏览器同步存储保存，不受这项口令加密保护。**

云吉 Tab 不收集分析数据。获取网站图标时会向 Google Favicon 服务发送网站域名。AI 分类是可选功能，需要自行配置 OpenAI 兼容服务；分类方案会先预览，确认后才应用，API Token 不参与同步或备份。数据存放位置、对外请求和权限用途见[隐私与权限说明](./docs/privacy.md)。

## 常用快捷键

| 快捷键                                            | 操作                   |
| ------------------------------------------------- | ---------------------- |
| `/`                                               | 聚焦搜索框             |
| `Cmd/Ctrl + K`                                    | 打开命令面板           |
| `N`                                               | 新增书签               |
| 方向键、`Enter`                                   | 选择并打开书签         |
| `Esc`                                             | 清空搜索或关闭当前弹层 |
| `Alt + Shift + B`（macOS：`Command + Shift + B`） | 快速收藏当前网页       |

主页快捷键可在「设置 → 快捷键」中修改。浏览器级快捷键在 `chrome://extensions/shortcuts` 中设置。

界面支持简体中文、繁体中文、英语、日语、韩语、西班牙语和法语。

## 开发与贡献

项目使用 Plasmo、React 和 TypeScript。准备 Node.js 22 或更高版本及 pnpm 10.34.4 后，可以从源码运行：

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

开发模式加载 `build/chrome-mv3-dev/`。构建、测试和代码目录说明见[开发指南](./docs/development.md)。

欢迎通过 [Issues](https://github.com/kiwiflydream/yunji-tab/issues) 提交问题和建议，也欢迎贡献代码。报告问题时，附上复现步骤、浏览器版本和截图，提交前隐藏私人网址与凭据。
