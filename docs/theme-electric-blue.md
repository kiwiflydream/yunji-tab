# 电光蓝主题

入口：设置 → 外观 → 整体风格 → 电光蓝。

主题借鉴参考图的灰白底、电蓝主文字、淡紫辅助文字和等宽排版，保留书签工作区的布局、导航、品牌图标和操作流程。

## 视觉规范

- 固定浅色，不跟随系统或深色模式改变配色。
- 主色为 `240 100% 45.5%`（约 `#0000E8`），背景为 `0 0% 95%`，辅助文字为 `246 33% 54%`。辅助文字在页面与控件底色上需保持可读对比度。
- 使用系统本地等宽字体，中文回退到本地中文字体，不加载远程字体或图片。
- 标题和控件使用 400 字重与正常字距；选中底色、边框保持浅淡，避免厚重的紫色块。
- 书签、书签组与目录不显示常驻边框，悬停时使用浅背景反馈且不浮起；菜单保留轻阴影，弹窗使用小圆角和轻遮罩。
- 保留用户选择的导航位置、猫咪装饰开关与卡片图标显示偏好；不引入参考图的排行榜内容和翼状标志。

## 维护约束

复用现有颜色变量、整体风格预设和设置持久化。主题启用时禁用强调色和背景选择，运行时也不允许这些偏好覆盖固定配色。

类型与归一化允许值在 `src/lib/types.ts`、`src/lib/appearance.ts`；配色使用 `electricPalette`，样式限定在 `html.theme-electric` 下。主题应用与退出时必须同步清理 `dark`、`theme-kami`、`theme-engraving` 和 `theme-electric`，避免样式残留。外观设置及提示文案覆盖所有支持的语言。

## 验证

`e2e/electric-theme.spec.ts` 覆盖设置入口选择、刷新后读回、导航位置保留、系统明暗切换、强调色覆盖保护、退出主题、书签组菜单，以及七种语言在 320px / 1280px 下的横向溢出。中英文设置界面还检查 axe 严重和致命问题。

按开发指南构建后，可运行 `pnpm exec playwright test e2e/electric-theme.spec.ts` 验证该主题。扩展测试使用临时浏览器配置，截图输出到 `/tmp/yunji-electric/`；提交前检查见 `docs/development.md`。

浏览器配置会在同一 worker 的测试文件间复用；主题测试结束后只清理自己创建的书签目录和书签组记录，避免影响其他主题测试。
