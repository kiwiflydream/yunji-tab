# 时间与天气

时间与天气沿用主页现有主题、字体、圆角与设置控件。

- 未配置外观或首次安装时使用晴空和居中首页；明确选择过的主题保留。
- 居中布局在首屏中间展示日期、天气和大号时间；工作台布局在桌面右上角展示等宽时间、次级日期、天气图标、温度与城市，细分隔线区分两组信息，不增加独立大卡片。两者都关闭时，居中布局的时间区整块收起。
- 窄屏保留时间与天气图标，将日期和城市详情收进设置，避免挤压搜索与操作按钮。
- 点击组件打开快捷配置；全部关闭后可以从设置的常规页重新开启。
- 晴空风格的居中布局会用天气作为首屏背景：晴（白天/夜晚）、多云、雾、雨、雪和雷暴各有一种纯 CSS 动画。背景只读取组件已加载的天气，不额外请求；未设置城市、加载中或失败时保持静态光晕。「天气背景」开关默认开启，保存在 `headerWidget.weatherBackground`；电光蓝等固定风格和工作台布局不显示，系统减少动态效果时全部静止。
- 时间跟随设备时区，可选 12/24 小时制与日期；天气支持城市搜索和摄氏/华氏切换。
- 未配置城市、加载、失败、权限拒绝、搜索无结果与保存失败均有对应状态。城市只能从搜索结果选择，避免名称与坐标不一致。
- 天气使用 Open-Meteo，按需申请域名权限，不自动定位；本地缓存 15 分钟，关闭后停止请求。
- 动效沿用控件的开关滑动、悬停底色和弹出层淡入缩放，尊重减少动态效果设置。

`e2e/header-widget.spec.ts` 使用固定天气响应验证配置、持久化、权限拒绝、保存失败与窄屏布局；`src/lib/weather.test.ts` 验证坐标校验、缓存、权限检查与接口响应。测试不自动获取设备定位，也不访问个人书签配置。
