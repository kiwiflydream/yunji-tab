# 隐私与权限说明

[返回 README](../README.md)

云吉 Tab 无需注册额外账号，也不收集分析数据。下面说明书签、补充数据和设置的存放位置，以及哪些操作会发出网络请求。

## 数据存放与同步

| 数据                                                         | 存放与同步方式                                                       |
| ------------------------------------------------------------ | -------------------------------------------------------------------- |
| 原生书签的名称、网址和文件夹                                 | 由浏览器管理，跨设备同步取决于浏览器的书签同步设置                   |
| 描述、标签、自定义图标、备用 URL、置顶和收件箱状态、目录图标 | 本地保存，默认通过浏览器同步存储跨设备同步，可选择字段并启用口令加密 |
| 书签组的标题、描述、图标、成员网址、组内名称、顺序和置顶状态 | 使用独立的浏览器同步存储，不受补充数据的字段选择和口令加密保护       |
| 界面与功能设置                                               | 使用浏览器同步存储；API Token 不参与同步                             |
| 访问记录、标签页会话、垃圾桶、操作历史和缓存                 | 保存在当前浏览器中                                                   |
| AI 服务的 API Token                                          | 本地保存，不参与同步或备份                                           |

跨设备同步需要两台设备使用同一 Chrome 账号、开启浏览器同步，并安装同一扩展。同步状态和补充数据的高级设置位于「设置 → 数据与隐私」。浏览器显示已上传不代表另一台设备已经接收，也不代表云吉 Tab 提供了独立的云端账号或服务器。

书签组按网址关联已有书签，避免依赖不同设备上的书签 ID。删除书签组不会删除原生书签。组配置包含在补充数据备份和完整快照中。

## 哪些操作会发出网络请求

### 网站图标

显示书签卡片时，扩展会按需向 Google Favicon 服务发送书签域名以获取图标，不发送书签路径、查询参数或页面内容。远程获取失败时，会回退到浏览器提供的网站图标接口。

如果为书签或书签组填写了自定义图片网址，浏览器会请求该图片资源。

### 备用 URL 选址

为书签配置备用 URL 后，点击书签时，扩展会同时请求主网址和备用地址，选择最先响应的入口。请求会发送到用户填写的各个地址。

### 网页信息与健康检查

用户主动获取网页描述或检查链接时，扩展才会申请访问对应网站。此类请求用于读取网页信息，或判断链接是否失效、重定向；可选授权可以在设置中撤销。

### AI 分类

AI 分类需要用户自行配置 OpenAI 兼容服务。运行分类时，会向所配置的服务发送书签标题、去除查询参数的网址、描述、标签和目录路径。数据由所选服务处理，使用前可查阅该服务的隐私政策。

扩展先生成分类和移动预览，用户确认后才修改书签目录。API Token 保存在本地，不参与同步或备份。

### 网页搜索

切换到网页搜索并提交关键词时，查询会交给所选的搜索引擎；未指定引擎时使用浏览器默认搜索服务。

## 权限用途

| 权限                               | 用途                                                       |
| ---------------------------------- | ---------------------------------------------------------- |
| `storage`                          | 保存设置、本地补充数据及跨设备同步数据                     |
| `bookmarks`                        | 读取和管理浏览器原生书签                                   |
| `favicon`                          | 通过浏览器接口获取网站图标                                 |
| `activeTab`                        | 用户触发快捷收藏或全局命令时读取当前页面                   |
| `scripting`                        | 按需向普通网页注入隔离的全局命令面板                       |
| `contextMenus`                     | 提供收藏当前页面的右键菜单                                 |
| `tabs`                             | 保存、恢复标签页会话，并复用主页标签页                     |
| `search`                           | 使用浏览器默认搜索服务执行网页搜索                         |
| `https://www.google.com/*`         | 请求 Google Favicon 服务                                   |
| `https://*.gstatic.com/*`          | 加载 Google 返回的图标资源                                 |
| 可选的 `http://*/*`、`https://*/*` | 在用户触发网页描述、链接检查或 AI 分类时访问指定网站或服务 |

全局命令面板默认关闭，开启及使用浏览器级快捷键时需要在扩展快捷键管理页分配按键。

## 备份、恢复与清理

「设置 → 数据与隐私」提供补充数据 JSON 导出、导入和完整快照。导入前可以预览冲突；完整快照恢复到新的 `Yunji Tab Restore ...` 文件夹，不会清空或覆盖现有书签。

通过云吉 Tab 删除书签或目录时，扩展会先保存本地快照，可以立即撤销或从「垃圾桶与历史」恢复。删除快照保留 30 天。

设置中可以分别清除访问记录、网站图标缓存、标签页会话、垃圾桶与历史、补充元数据及可选网站授权。清除补充元数据不会删除浏览器原生书签，但会清除其同步副本。书签组是独立数据，可在书签组入口中管理或删除。

报告问题时，请隐藏 API Token、私人网址和浏览记录。截图和导出的备份可能包含这些数据，不建议直接附在公开 Issue 中。
